# ⚡ Terminal Cheatsheet

---

## 󰕮 Paneles — `Ctrl+p`, luego...

| Tecla | Acción |
|:------|:-------|
| `h` `j` `k` `l` | Navegar entre paneles |
| `H` `J` `K` `L` | Resize del panel |
| `f` | Fullscreen / salir fullscreen |
| `Esc` | Volver al shell |

---

## 󰓩 Tabs — `Ctrl+y`, luego...

| Tecla | Acción |
|:------|:-------|
| `c` | Nueva tab |
| `x` | Cerrar tab |
| `n` | Tab siguiente |
| `p` | Tab anterior |
| `r` | Renombrar tab → `Enter` confirma |
| `1` `2` `3` `4` `5` | Ir directo a tab |
| `Esc` | Volver al shell |

---

## 󰮊 Paneles rápidos

| Atajo | Acción |
|:------|:-------|
| `Ctrl+n` | Nuevo panel |
| `Ctrl+\` | Panel a la derecha |
| `Ctrl+-` | Panel abajo |
| `Ctrl+x` | Cerrar panel |

---

## 󰆍 Shell

| Atajo | Acción |
|:------|:-------|
| `Ctrl+l` | Limpiar terminal |
| `Ctrl+u` | Scroll arriba |
| `Ctrl+d` | Scroll abajo |

---

## 󰕷 LazyVim — `Space` como leader

| Atajo | Acción |
|:------|:-------|
| `Space e` | File explorer |
| `Space Space` | Buscar archivos |
| `Space s g` | Buscar texto en el proyecto |
| `Space g g` | LazyGit |
| `Space g d` | Diff view |
| `Space g f` | Historial del archivo |
| `Space g b` | Toggle git blame |
| `Space s t` | Listar TODOs del proyecto |
| `Space u c` | Cambiar tema de color |
| `Space l` | Gestión de plugins |
| `g d` | Ir a definición |
| `K` | Documentación del símbolo |
| `Shift+h` / `Shift+l` | Buffer anterior / siguiente |
| `Space b d` | Cerrar buffer |
